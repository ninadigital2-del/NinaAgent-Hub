Content Calendar

ใช้ได้

ดูงานรายเดือน สลับเดือนได้ คลิกรายการเพื่อดูรายละเอียด

ลากวางเลื่อนวันโพสต์

ใช้ได้

ลากการ์ดใน Calendar ไปวางวันใหม่เพื่อเลื่อนกำหนดโพสต์ โดยไม่ต้องเปิดฟอร์มแก้ไข

Checklist ก่อนโพสต์

ใช้ได้

ตรวจสถานะความพร้อม: มี Caption ครบ / มีสื่อ / มี CTA / ระบุวันเวลา / ผู้รับผิดชอบ / ผ่านอนุมัติ

ตัวกรอง แบรนด์ / ผู้รับผิดชอบ / แพลตฟอร์ม

ใช้ได้

แถบตัวกรองด้านบนสุด เลือกดูเฉพาะแบรนด์ ผู้รับผิดชอบ หรือแพลตฟอร์มที่ต้องการ ใช้ร่วมกันทั้ง Dashboard, Calendar, List, รายงาน

เลือกเดือนในหน้ารายการทั้งหมด / รายงาน

ใช้ได้

มีปุ่มเลื่อนเดือนก่อนหน้า/ถัดไป และปุ่ม "เดือนนี้" (ค่าเริ่มต้นคือเดือนปัจจุบัน) ให้ดูข้อมูลเฉพาะเดือนที่เลือกในหน้า "รายการทั้งหมด" และ "รายงาน" (Dashboard ไม่ใช้ตัวกรองนี้ — ดูข้อมูลทั้งระบบเสมอ)

Bulk Actions (เลือกหลายรายการ)

ใช้ได้

ติ๊กเลือกหลายรายการในหน้า List แล้วเปลี่ยนสถานะพร้อมกันได้ทีเดียว

ลบรายการถาวร

ใช้ได้

เปิดรายละเอียดคอนเทนต์ (จาก Calendar หรือ List ก็ได้) กดปุ่ม "ลบ" สีแดงมุมล่างซ้าย ยืนยันแล้วลบทั้งแถวในชีทและ event ในปฏิทินให้อัตโนมัติ — ย้อนกลับไม่ได้ ใช้อย่างระวัง

ไอคอนแพลตฟอร์มจริง

ใช้ได้

หน้า "รายการทั้งหมด" และหน้ารายละเอียด แสดงโลโก้ Facebook/Instagram/TikTok/LINE/YouTube จริงคู่กับชื่อแพลตฟอร์ม แทนตัวหนังสือล้วน

ลิงก์งานสำหรับให้ลูกค้าคอมเมนต์

ใช้ได้

ลิงก์ที่แปะไว้ตอนสร้างคอนเทนต์ (เช่น Canva/Drive) จะแสดงเป็น "ลิงก์งาน (กดดู/คอมเมนต์ได้)" ใต้ชื่อผู้รับผิดชอบในหน้ารายละเอียด ให้ลูกค้ากดเข้าไปดูหรือคอมเมนต์ที่ต้นทางได้เลย

โหมดลูกค้า + สร้างลิงก์ส่งให้ลูกค้า

ใช้ได้

กดปุ่ม "โหมดลูกค้า" มุมขวาบน → เลือกแบรนด์ลูกค้าจาก popup → ระบบสร้างลิงก์เฉพาะแบรนด์นั้นและคัดลอกเข้า clipboard ให้อัตโนมัติ ส่งลิงก์นี้ให้ลูกค้าได้เลย เปิดแล้วจะเห็นเฉพาะแบรนด์ตัวเอง มีแถบสีเขียวบอกชัดว่ากำลังอยู่โหมดลูกค้า ดูได้ทุกอย่าง เปลี่ยนสถานะ (Review/Revision/Approved) และคอมเมนต์ได้ แต่แก้ไข/ลบ/สร้างรายการใหม่ไม่ได้ — ลิงก์แบบนี้ไม่มีปุ่มให้สลับกลับไปโหมดแก้ไขเต็มด้วย

ความคิดเห็นต่อรายการ (Comments)

ใช้ได้

แสดงความเห็น/ขอแก้ไขตรงจุดในแต่ละคอนเทนต์ ทั้งทีมและลูกค้า (โหมดลูกค้า) คอมเมนต์ได้

รายงานเบื้องต้น

ใช้ได้

สรุปจำนวนงานแยกตามแพลตฟอร์ม/แบรนด์ และอัตราการโพสต์ตรงเวลา — รองรับตัวกรองแบรนด์/ผู้รับผิดชอบ/แพลตฟอร์ม และตัวเลือกเดือนแล้ว

เลือกแบรนด์ / ผู้รับผิดชอบแบบ Dropdown

ใช้ได้

แบรนด์ต้องเลือกจาก Notion "Brand" database เท่านั้น (เฉพาะที่ Active) — ไม่มีปุ่มเพิ่มแบรนด์ใหม่เองแล้ว ถ้าเป็นแบรนด์ใหม่จริงต้องไปสร้างใน Notion ก่อน แล้วรอ sync ถึงจะเลือกได้ที่นี่ (กันชื่อแบรนด์เพี้ยน/ซ้ำซ้อน) ส่วนผู้รับผิดชอบ/ผู้ตรวจ (จาก "Owner for Grouping") ยังพิมพ์ชื่อใหม่เองได้ถ้าจำเป็น

นำเข้าจากรูปปฏิทิน (Canva)

ใช้ได้ (ต้องเชื่อม backend)

แปะรูปปฏิทินที่ทำจาก Canva ในหน้า Calendar → AI (Gemini Vision) อ่านและแยกรายการให้ → ตรวจสอบ/แก้ไขในตารางรีวิวก่อน → กดสร้างทั้งหมดเป็น batch เดียว (แบบเดียวกับ GEM Capacity Board) ต้องตั้งค่า GEMINI_API_KEY ใน Script Properties ก่อนใช้งาน

แจ้งเตือนผ่าน LINE อัตโนมัติ

ใช้ได้ (ต้องเชื่อม backend)

ทุกเช้า 8:15 น. ระบบส่งการ์ด LINE Flex Message สวยๆ (รวมทุกงานวันเดียวกันไว้ในข้อความเดียว) เตือน 3 จังหวะ: อีก 2 วัน และ พรุ่งนี้ (เฉพาะงานที่ยังไม่ Ready/Approved) และ วันนี้ (ทุกกรณี) — แต่ละการ์ดโชว์ชื่องาน แบรนด์ แพลตฟอร์ม ผู้รับผิดชอบ และวันเวลาที่ต้องโพสชัดเจน สถานะ Scheduled จะไม่ถูกเตือนเลย

กดปุ่มในการ์ดได้เลย ไม่ต้องเปิดเว็บ — การ์ด "อีก 2 วัน"/"พรุ่งนี้" มีปุ่ม ✅ พร้อมแล้ว (เปลี่ยนสถานะเป็น Ready ทันที) การ์ด "วันนี้" มีปุ่ม ✅ โพสแล้ว (Posted) และ 📅 ตั้งเวลาโพสไว้แล้ว (Scheduled — เผื่อไปตั้งคิวไว้ในเครื่องมืออื่นแล้ว) กดแล้ว LINE จะตอบกลับยืนยันทันที และสถานะในระบบจะเปลี่ยนจริง — ถ้างานมีหลายแพลตฟอร์ม ให้กด "โพสแล้ว" ตอนโพสครบทุกแพลตฟอร์มแล้วเท่านั้น

Sync เข้า Google Calendar กลาง

ใช้ได้ (ต้องเชื่อม backend)

ทุกคอนเทนต์จะมี event บนปฏิทินกลาง "NinaAgent Hub - Content Planner" อัตโนมัติ อัปเดตเมื่อแก้ไข ลบเมื่อ Cancelled — PM subscribe ปฏิทินนี้ครั้งเดียวก็เห็นตารางโพสต์ทั้งหมดในปฏิทินตัวเองได้เลย (ดูวิธี subscribe ใน SETUP.md)

บันทึกข้อมูลถาวร (Google Sheets)

ใช้ได้

ข้อมูลทุกอย่างบันทึกลง Google Sheets จริง ไม่หายเมื่อรีเฟรชหน้า — ถ้าเห็นแถบสีแดง "เชื่อมฐานข้อมูลไม่สำเร็จ" มุมขวาบน แปลว่าเน็ตเวิร์กมีปัญหาชั่วคราว ระบบจะสลับไปใช้ข้อมูลจำลองแทนจนกว่าจะเชื่อมได้ใหม่

วิธีใช้งานเบื้องต้น

1
สร้างคอนเทนต์ใหม่ — กดปุ่ม "สร้างคอนเทนต์" มุมขวาบน กรอกแบรนด์ แคมเปญ หัวข้อ เลือกแพลตฟอร์ม แล้วเตรียม Caption ของแต่ละแพลตฟอร์มในแท็บที่ปรากฏ
2
ตรวจความพร้อม — ดู Checklist ด้านล่างฟอร์ม ถ้ายังไม่ครบจะมีจุดสีเทาบอกว่าขาดอะไร กรอกให้ครบก่อนเปลี่ยนสถานะเป็น Approved/Ready
3
ติดตามงานประจำวัน — เข้าแท็บ "หน้ารวมงานวันนี้" เพื่อดูงานที่ต้องโพสต์วันนี้ เลยกำหนด หรือรอตรวจ
4
วางแผนล่วงหน้า — เข้าแท็บ Calendar ดูภาพรวมทั้งเดือน ลากการ์ดไปวันอื่นได้ถ้าต้องเลื่อนกำหนด
5
กรองดูเฉพาะที่ต้องการ — ใช้ filter bar ด้านบน (แบรนด์/ผู้รับผิดชอบ/แพลตฟอร์ม) เพื่อโฟกัสเฉพาะงานที่เกี่ยวข้อง และในหน้า "รายการทั้งหมด"/"รายงาน" เลื่อนเดือนดูย้อนหลังหรือล่วงหน้าได้จากปุ่มเลือกเดือนด้านบน
6
อัปเดตหลังโพสต์จริง — เปิดรายการ กดแก้ไข เปลี่ยนสถานะเป็น "Posted" แล้วบันทึกลิงก์โพสต์จริง (ปิด popup ได้ทั้งปุ่ม "ปิด" ด้านล่าง หรือกากบาทมุมขวาบน) งานที่ตั้งไว้ล่วงหน้าในเครื่องมืออื่นแล้วให้เปลี่ยนเป็น "Scheduled" แทน จะได้ไม่โดนแจ้งเตือนซ้ำ ส่วนงานที่สร้างผิด/ไม่ใช้แล้วกดปุ่ม "ลบ" สีแดงในหน้ารายละเอียดได้เลย (ลบถาวร ย้อนกลับไม่ได้)
7
ส่งลิงก์ให้ลูกค้าดูความคืบหน้า — กดปุ่ม "โหมดลูกค้า" มุมขวาบน → เลือกแบรนด์ของลูกค้าจาก popup → ลิงก์เฉพาะแบรนด์นั้นถูกคัดลอกเข้า clipboard ให้อัตโนมัติ วางส่งให้ลูกค้าได้เลย เปิดลิงก์แล้วลูกค้าจะเห็นเฉพาะแบรนด์ตัวเอง ดูทุกอย่างได้ เปลี่ยนสถานะ/คอมเมนต์ได้ แต่แก้ไข/ลบ/สร้างใหม่ไม่ได้ — ถ้าแค่อยากดูตัวอย่างเองในเครื่อง กดลิงก์เล็กๆ ท้าย popup "ดูตัวอย่างโหมดลูกค้าในหน้านี้เลย" แทนได้

สถานะของคอนเทนต์

Draft Review Revision Approved Ready Scheduled Posted

ระบบจะคำนวณสถานะเพิ่มเติมให้อัตโนมัติ: กำลังจะถึงกำหนด (ภายใน 24 ชม.), เลยกำหนด, ข้อมูลครบแล้ว และ ข้อมูลไม่ครบ — แสดงเป็นสีบนหน้า Dashboard และ List

Scheduled = ตั้งเวลาโพสต์ล่วงหน้าไว้ในเครื่องมืออื่นแล้ว (เช่น Meta Business Suite) ระบบจะไม่ส่งการแจ้งเตือน LINE ให้รายการที่อยู่ในสถานะนี้เลย

สิ่งที่ยังไม่รวมในเวอร์ชันนี้

  • การโพสต์เข้าแพลตฟอร์มอัตโนมัติ — ยังต้องคัดลอกข้อความไปโพสต์เองในแต่ละแอป
  • ระบบตรวจสอบว่า "ผู้กดปุ่ม" ใน LINE เป็นเจ้าของงานจริงมั้ย — ตอนนี้ยังไม่มี guard เพราะแต่ละคนได้รับข้อความแยกกันคนละแชท (ยังไม่ใช่ group เดียวกัน) ความเสี่ยงกดผิดคนต่ำ แต่ถ้าย้ายไปเป็น LINE group เดียวกันในอนาคตควรเพิ่มการตรวจสอบนี้
  • ระบบ Login และสิทธิ์ผู้ใช้แบบเต็มรูปแบบ — "โหมดลูกค้า" ตอนนี้ป้องกันได้แค่ระดับ UI (ซ่อนปุ่มแก้ไข/ลบ + ลิงก์เฉพาะแบรนด์) ยังไม่ใช่การล็อกสิทธิ์จากฝั่ง server จริง ผู้ใช้ที่มีความรู้ทางเทคนิคยังสามารถเลี่ยงได้ทางหลักการ
