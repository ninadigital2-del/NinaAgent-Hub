Content Calendar

ใช้ได้

ดูงานรายเดือน สลับเดือนได้ คลิกรายการเพื่อดูรายละเอียด

ลากวางเลื่อนวันโพสต์

ใช้ได้

ลากการ์ดใน Calendar ไปวางวันใหม่เพื่อเลื่อนกำหนดโพสต์ โดยไม่ต้องเปิดฟอร์มแก้ไข

Checklist ก่อนโพสต์

ใช้ได้

ตรวจสถานะความพร้อม: มี Caption ครบ / มีสื่อ / มี CTA / ระบุวันเวลา / ผู้รับผิดชอบ / ผ่านอนุมัติ

ตัวกรองแบรนด์ / แพลตฟอร์ม

ใช้ได้

เลือกดูเฉพาะแบรนด์หรือแพลตฟอร์มที่ต้องการ ใช้ร่วมกันทั้ง Dashboard, Calendar, List

Bulk Actions (เลือกหลายรายการ)

ใช้ได้

ติ๊กเลือกหลายรายการในหน้า List แล้วเปลี่ยนสถานะพร้อมกันได้ทีเดียว

โหมดลูกค้า (อ่านอย่างเดียว)

ใช้ได้

เปิดโหมดนี้เพื่อซ่อนปุ่มสร้าง/แก้ไข เหมาะสำหรับให้ลูกค้าดูสถานะงานโดยไม่แก้ข้อมูล

ความคิดเห็นต่อรายการ (Comments)

ใช้ได้

แสดงความเห็น/ขอแก้ไขตรงจุดในแต่ละคอนเทนต์ ทั้งทีมและลูกค้า (โหมดลูกค้า) คอมเมนต์ได้

รายงานเบื้องต้น

ใช้ได้

สรุปจำนวนงานแยกตามแพลตฟอร์ม/แบรนด์ และอัตราการโพสต์ตรงเวลา

เลือกแบรนด์แบบ Dropdown

ใช้ได้

ตอนสร้างคอนเทนต์ เลือกแบรนด์จากลิสต์ที่มีอยู่ หรือเลือก "+ เพิ่มแบรนด์ใหม่" เพื่อพิมพ์ชื่อแบรนด์ใหม่

นำเข้าจากรูปปฏิทิน (Canva)

Phase 2

แปะรูปปฏิทินที่ทำจาก Canva แล้วให้ระบบอ่านและสร้างรายการอัตโนมัติ (แบบเดียวกับ GEM Capacity Board) — ต้องเชื่อม Apps Script + Gemini Vision API ก่อน ปุ่มอัปโหลดมีให้ลองแล้วในหน้า Calendar แต่ยังไม่ประมวลผลจริง

แจ้งเตือนอีเมลอัตโนมัติ

Phase 3

เตือนก่อนโพสต์ 24 ชม. / 1 ชม. เตือนข้อมูลไม่ครบ เลยกำหนด — ต้องเชื่อม Google Apps Script ก่อน

บันทึกข้อมูลถาวร (Google Sheets)

Phase 2

ตอนนี้ข้อมูลเป็นตัวอย่างจำลอง รีเฟรชหน้าแล้วจะรีเซ็ตกลับค่าเดิม — Phase 2 จะเชื่อมฐานข้อมูลจริง

วิธีใช้งานเบื้องต้น

1
สร้างคอนเทนต์ใหม่ — กดปุ่ม "สร้างคอนเทนต์" มุมขวาบน กรอกแบรนด์ แคมเปญ หัวข้อ เลือกแพลตฟอร์ม แล้วเตรียม Caption ของแต่ละแพลตฟอร์มในแท็บที่ปรากฏ
2
ตรวจความพร้อม — ดู Checklist ด้านล่างฟอร์ม ถ้ายังไม่ครบจะมีจุดสีเทาบอกว่าขาดอะไร กรอกให้ครบก่อนเปลี่ยนสถานะเป็น Approved/Ready
3
ติดตามงานประจำวัน — เข้าแท็บ "หน้ารวมงานวันนี้" เพื่อดูงานที่ต้องโพสต์วันนี้ เลยกำหนด หรือรอตรวจ
4
วางแผนล่วงหน้า — เข้าแท็บ Calendar ดูภาพรวมทั้งเดือน ลากการ์ดไปวันอื่นได้ถ้าต้องเลื่อนกำหนด
5
กรองดูเฉพาะที่ต้องการ — ใช้ filter bar ด้านบน (แบรนด์/แพลตฟอร์ม) เพื่อโฟกัสเฉพาะงานที่เกี่ยวข้อง
6
อัปเดตหลังโพสต์จริง — เปิดรายการ กดแก้ไข เปลี่ยนสถานะเป็น "Posted" แล้วบันทึกลิงก์โพสต์จริง
7
ให้ลูกค้าดูความคืบหน้า — เปิด "โหมดลูกค้า" มุมขวาบน เพื่อซ่อนปุ่มแก้ไขทั้งหมด เหมาะกับการแชร์หน้าจอให้ลูกค้าดูสถานะงาน หรือให้ลูกค้าคอมเมนต์ขอแก้ไขได้เอง

สถานะของคอนเทนต์

Draft Review Revision Approved Ready Posted

ระบบจะคำนวณสถานะเพิ่มเติมให้อัตโนมัติ: กำลังจะถึงกำหนด (ภายใน 24 ชม.), เลยกำหนด, และ ข้อมูลไม่ครบ — แสดงเป็นสีบนหน้า Dashboard และ List

สิ่งที่ยังไม่รวมในเวอร์ชันนี้

  • การโพสต์เข้าแพลตฟอร์มอัตโนมัติ — ยังต้องคัดลอกข้อความไปโพสต์เองในแต่ละแอป
  • การบันทึกข้อมูลถาวร — ตอนนี้เป็นข้อมูลจำลอง รีเฟรชหน้าแล้วรีเซ็ต (จะเชื่อม Google Sheets ใน Phase 2)
  • ระบบแจ้งเตือนอีเมลอัตโนมัติ (จะทำใน Phase 3)
  • ระบบ Login และสิทธิ์ผู้ใช้แบบเต็มรูปแบบ — โหมดลูกค้าตอนนี้เป็นการสลับมุมมองในเครื่องเดียว ยังไม่ใช่ระบบสิทธิ์จริง
