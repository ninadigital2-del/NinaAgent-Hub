# คู่มือ Meeting → Notion Agent Pro (ฉบับ พ.ย. 2026)

ฉบับร่างสำหรับ PM แทนคู่มือ PDF เดิมที่ใช้รูปหน้าจอเก่า ยังไม่มีรูปหน้าจอ ควรเพิ่มรูปจากหน้าจริงหลัง PM ลองใช้

**ใช้ทำอะไร:** เอาข้อมูลประชุมทุกแบบ (เสียง, โน้ตลายมือ, PDF, Word, แชท LINE) มารวมเป็นข้อความเดียว ให้ AI แยกเป็น Project และ Task แล้วสร้างใน Notion โดยใช้กฎเดียวกับ Capacity Board

**เปิดจากไหน:** Hub → Meeting Agent

---

## ขั้น 1 — INPUT: ใส่ข้อมูลประชุม

1. กรอก **ชื่อการประชุม** และ **วันที่ประชุม** (ค่าเริ่มต้นคือวันนี้) วันที่นี้สำคัญ: AI จะนับ deadline ที่พูดว่า "พรุ่งนี้" "สัปดาห์หน้า" จากวันนี้ ไม่ใช่จากวันที่กดปุ่ม ถ้าเอาข้อมูลเข้าช้า ต้องแก้วันที่ให้ตรงกับวันประชุมจริง
2. ใส่ไฟล์ได้ 3 ทาง ใส่ปนกันได้กี่ไฟล์ก็ได้:

| ทาง | ใช้เมื่อ |
|---|---|
| **ลากไฟล์มาวาง** หรือกดกล่อง "📎 ลากไฟล์มาวางที่นี่" | ไฟล์ในเครื่อง **ไม่เกิน 8MB** (รูปโน้ต, PDF, Word, เสียงสั้น, .txt) |
| **วางลิงก์ / ID ไฟล์จาก Google Drive** แล้วกด "+ เพิ่มไฟล์" | ไฟล์ใหญ่ เช่น เสียงประชุม 30–90 นาที (ไม่เกิน ~48MB) |
| **พิมพ์หรือวางข้อความ** ในช่องข้อความด้านล่างเลย | บันทึกประชุมที่พิมพ์ไว้แล้ว หรือแชทที่ copy มา |

3. แต่ละไฟล์เป็นการ์ด: ⏳ กำลังแปลง → ✅ เสร็จ (ข้อความถูกใส่ในช่องด้านล่างแล้ว) หรือ ❌ ไม่สำเร็จ มีปุ่ม "ลองใหม่" กด × เพื่อลบการ์ด (ข้อความที่ใส่ไปแล้วต้องลบเองในช่องข้อความ)

**ชนิดไฟล์ที่รองรับ**

| ชนิด | หมายเหตุ |
|---|---|
| เสียง (.m4a .mp3 .wav ฯลฯ) | ถอดเป็นข้อความด้วย Gemini ส่วนที่ฟังไม่ชัดจะเขียนว่า `[ฟังไม่ชัด]` |
| รูปโน้ต / ลายมือ / screenshot | ส่วนที่อ่านไม่ออกจะเขียนว่า `[อ่านไม่ออก]` ไม่เดาให้ |
| PDF, Word (.docx), Google Doc | ดึงข้อความทั้งหมด ไม่สรุป |
| .txt จาก LINE | อ่านตรงๆ ไม่ใช้ AI **วางหรือใส่ทั้งไฟล์ อย่าตัดวันที่และชื่อผู้ส่งทิ้ง** เพราะ AI ใช้วันที่ของข้อความนับ deadline |

**ไฟล์ใน Drive ต้อง:** บัญชีเจ้าของระบบ Meeting Agent เปิดไฟล์นั้นได้ (แชร์ให้บัญชีนั้น หรือเป็นไฟล์ของบัญชีนั้นเอง)

**ข้อจำกัด**
- ไฟล์ใหญ่กว่า ~48MB ระบบปฏิเสธ ให้ตัดเป็นช่วงสั้นลงแล้วแปลงทีละช่วง
- ถ้าข้อความที่ถอดถูกตัดเพราะยาวเกิน ระบบจะแจ้ง error ไม่ใช้ข้อความที่ขาดครึ่ง ให้ตัดไฟล์สั้นลงแล้วลองใหม่
- แชท LINE ที่ export เป็น .txt ไม่มีข้อความเสียงและรูปในแชท ถ้าสำคัญให้บันทึกออกมาแล้วใส่เป็นไฟล์แยก

## ขั้น 2 — REVIEW: ตรวจข้อความ แล้วกด "▶ วิเคราะห์ด้วย Gemini"

- อ่านช่องข้อความรวม แก้คำผิด ลบส่วนที่ไม่เกี่ยว ส่วนที่มาจากแต่ละไฟล์จะมีหัวบอกที่มา เช่น `=== 🎙️ เสียงประชุม · ชื่อไฟล์ ===`
- กด **▶ วิเคราะห์ด้วย Gemini** AI จะแยก Project และ Sub-task ให้ พร้อมจับคู่กับ Project ที่มีอยู่ใน Notion (เฉพาะ Project ที่ยังไม่ปิด)
- ข้อความที่ตรวจแล้วถูกเก็บไว้ใน Drive โฟลเดอร์ `Meeting Agent Uploads/<วันที่> <ชื่อประชุม>/transcript.txt`

## ขั้น 3 — CONFIRM: ตรวจ Task แล้วกด "✓ สร้างใน Notion"

ผลลัพธ์แต่ละ Project มีสถานะจับคู่:

| สถานะ | ความหมาย | ต้องทำ |
|---|---|---|
| exact | ตรงกับ Project ใน Notion | ตรวจชื่อ Task และวันที่ |
| uncertain | AI ไม่แน่ใจ | เลือกว่าจะผูกกับ Project ไหน หรือสร้างใหม่ |
| new | Project ใหม่ | กรอกช่องด้านล่างให้ครบ |

**Project ใหม่ต้องกรอก**

| ช่อง | บังคับ | หมายเหตุ |
|---|---|---|
| Brand | ✅ | เลือกจากรายชื่อ Brand ใน Notion |
| PM Owner | ✅ | เลือกจาก PM ที่ Active ในทีม ถ้าไม่เลือก ระบบไม่สร้าง Project นี้ |
| Service Type | ไม่บังคับ | ไม่เลือก = Content / Graphic |
| ผู้ติดต่อ (Contacts) | ไม่บังคับ | โหลดตาม Brand ที่เลือก |
| Scope Item (ใบเสนอราคา) | ไม่บังคับ | โหลดตาม Brand ที่เลือก |

- ตรวจ Sub-task แต่ละอัน: ชื่อ, ประเภทงาน (Work Type), วันครบกำหนด แก้ได้ก่อนส่ง
- **Work By, Task Type, Financial Risk** ระบบเติมให้ตามประเภทงานโดยอัตโนมัติ เหมือนที่ Capacity Board ทำ AI ไม่ได้เดาค่าเหล่านี้
- **ไม่มีการมอบงานให้ช่าง Graphic ที่นี่** หลังสร้างแล้ว ไปมอบงานใน Capacity Board ซึ่งเห็นภาระงานของช่างแต่ละคน
- กด **✓ สร้างใน Notion** ถ้าบางรายการสร้างไม่สำเร็จ ระบบแจ้งรายการที่ผิดพลาด ส่วนที่สำเร็จแล้วสร้างไปแล้ว

## ถ้าเจอปัญหา

| อาการ | ทำอย่างไร |
|---|---|
| ❌ "ไฟล์ใหญ่เกิน 8 MB" ตอนลากไฟล์ | อัปโหลดไฟล์เข้า Drive แล้ววางลิงก์ |
| ❌ "ไฟล์ใหญ่เกิน 48 MB" | ตัดไฟล์เสียงเป็นช่วงสั้นลง |
| ❌ เปิดไฟล์ Drive ไม่ได้ | แชร์ไฟล์ให้บัญชีเจ้าของระบบ แล้วกด "ลองใหม่" |
| ❌ ข้อความที่ถอดถูกตัด | ตัดไฟล์สั้นลงแล้วลองใหม่ |
| หน้าจอขึ้น error ตอนเปิดหน้า ไม่มีรายการ Project/Brand/PM | ระบบอ่าน Notion ไม่ได้ จะไม่ใช้รายชื่อสำรอง แจ้งผู้ดูแลระบบ |
| Task ไม่ขึ้นใน Capacity Board | ปกติ ต้องไปมอบงานให้ช่างใน Capacity Board ก่อน |

**สำหรับผู้ดูแลระบบ:** ครั้งแรกหลัง deploy ให้เจ้าของสคริปต์เปิด editor แล้ว Run `meetingBootstrap` 1 ครั้ง กด Allow สิทธิ์ Drive/Docs ไม่เช่นนั้นไฟล์แรกที่ PM ใส่จะ error เรื่องสิทธิ์
